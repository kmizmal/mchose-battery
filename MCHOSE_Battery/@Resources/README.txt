MCHOSE 电量 · Rainmeter 皮肤（鼠标 + 键盘）
==========================================

两张卡片
--------
目录下有两个 .ini，在 Rainmeter 里就是两张独立皮肤，可以同时加载、互不干扰：
· Mouse\V7Battery.ini      —— 迈从 MCHOSE V7 鼠标
· Keyboard\G87Battery.ini  —— 迈从 MCHOSE G87 键盘
安装包默认只加载 Keyboard\G87Battery.ini；另一张在托盘图标右键 → 皮肤 →
MCHOSE_Battery → Mouse 里手动加载（Rainmeter 的安装器一次只能 Load 一张）。
两张各自存自己的状态（v7-state.txt / g87-state.txt），不会互相覆盖。

用途
----
在桌面上显示迈从设备的连接状态与剩余电量：
· 已连接时显示百分比、进度条、连接方式（2.4G / 有线）与充放电状态
· 电量低于 20% 转为橙色并提示「电量偏低」，低于 8% 转为红色「电量极低」
· 鼠标休眠或断开时显示「已断开」，数字保留最后一次读数并转灰，左键点击卡片可立即重新采集
· 左上角是官方产品图，中键点击卡片循环配色
  （鼠标：白 / 黑 / 红 / 粉；键盘：白 / 黑 / 青 / 粉 —— G87 官方配色里没有红色）
· 暗色卡片，默认整体 80% 不透明；可在 Variables.inc 调 OpacityValue（255 = 完全不透明）
· 进度条平时是 3px 细线，鼠标移到条区会展开成 8px 的圆角胶囊条

操作
----
· 左键点卡片：立即采集一次
· 中键点卡片：切换产品图配色（鼠标四色 / 键盘四色）
· 鼠标移到进度条上：细线展开成粗条，移开恢复
（皮肤不弹提示框，说明都写在本文档与 Rainmeter 管理面板的简介里）

安装
----
方式一：双击 MCHOSE_Battery_1.1.rmskin，按提示安装。
        安装器会把插件放到 Rainmeter 的 Plugins 目录，皮肤放到 Skins 目录。
方式二：手动安装，需要两步，缺一不可：
        1) 把 MCHOSE_Battery 整个文件夹复制到
           %USERPROFILE%\Documents\Rainmeter\Skins\
        2) 把 MCHOSE_Battery.dll 复制到
           Rainmeter 安装目录\Plugins\（例如
           %LOCALAPPDATA%\Programs\Rainmeter\Plugins\）
        然后托盘图标右键 → 管理 → 刷新全部 → 加载 MCHOSE_Battery。

依赖
----
无外部依赖。数据由 MCHOSE_Battery.dll 直接读 HID，不需要 Python、hidapi 或任何
后台进程。插件是 64 位，必须配 64 位 Rainmeter。

数据从哪来
----------
1. 卡片里的主实例（[MeasureV7] / [MeasureG87]）每 20 分钟触发一次采集；
2. 鼠标：枚举 VID_3837、UsagePage 0xFF01/0xFF0B 的接口，发 64 字节 0x4D 帧
   （命令 0x0900），连续 6 次无应答时回退到前代 0x11 Feature 通道。
   连接方式与充电状态按官方规则判定：
     · 连接方式看应答来自哪个设备：2.4G 档由鼠标本体 0x1016(4118) 应答
       （在官方无线名单 nT=[4116,4120,4124,4118,4125] 内）→ 显示「2.4G 无线」；
       有线档由接收器 0x402A 应答 → 显示「有线」；
       蓝牙档的 HID 身份是 VID_05AC / PID_0x024F，**没有任何厂商自定义集合**
       （0x4D 帧无处可发，实测写 20 字节通道返回 87），电量改读系统的
       BLE GATT Battery Service → 显示「蓝牙」。三档自动识别；
     · 仅插 USB 线不改变档位，那只是充电；
     · 充电中看 chargeStatus 是否精确等于 1（0x02 表示未充电）；
     · 蓝牙档只能拿到百分比，**没有充电状态**，界面不显示充/放电，属正常；
3. 键盘（2.4G 档 / 蓝牙档共用同一协议）：枚举厂商自定义页上的 20 字节收发接口，
   发 0x13 帧（命令 0x4A）；2.4G 身份是 VID_41E4，蓝牙身份是 VID_3554 / PID_0xFA07。
   应答第 5 字节是电量、第 6 字节是状态（低 4 位 = 满电，高 4 位 = 充电中），
   校验为全部字节求和；
4. 键盘插上 Type-C：只是充电，数据链路不变，仍走 0x4A 读取，
   status 高 4 位置起充电标志，卡片显示「充电中」；
5. 键盘切到「有线模式」：会额外枚举出 PID 0x2201 / UsagePage 0xFF00，
   改走 Feature 报告 0x06 —— 发 520 字节（命令 0x87），
   回读后同样取电量与状态，卡片显示「有线」；
   三条通道自动识别（有线 > 蓝牙 > 2.4G），插拔线 / 切档都不用改任何设置；
6. 键盘切到「蓝牙档」：USB 身份消失，Windows 以 BLE HID 重新枚举
   （VID_3554 / PID_0xFA07，usagePage 0xFF02、20 字节收发、无 Feature 通道），
   0x13/0x4A 帧与 2.4G 逐字节相同，卡片显示「蓝牙」；
5. 结果归一化成状态码后直接喂给各 Meter，不再经过 JSON 文件或 Lua。
   最后一次成功读数会写进 @Resources 下的 v7-state.txt / g87-state.txt，
   掉线时继续沿用，不会清零。

常见问题
--------
· 显示「异常」：插件没加载或位数不符。
  确认 Rainmeter 安装目录的 Plugins 下有 MCHOSE_Battery.dll；换过 DLL 后要重启 Rainmeter。
· 显示「已断开」但鼠标在用：鼠标休眠时接收器不代答，移动鼠标唤醒后会自动恢复；
  也可以左键点击卡片手动重试。
· 键盘卡片显示「已断开」：键盘休眠时接收器不代答，敲任意键唤醒后会自动恢复；
  也可以左键点击卡片手动重试。2.4G / 蓝牙 / 有线三种档位都支持自动识别。
· 键盘插上 Type-C 线后：仍以 2.4G 身份工作（插线只是充电），
  卡片显示「2.4G 无线」+「充电中」，电量照常读取。
· 键盘切到「有线模式」后：卡片自动显示「有线」+「充电中」，
  插件改走 Feature 报告通道读取（已实测通过）。
· 鼠标切到「蓝牙档」后：卡片自动显示「蓝牙」（已实测通过）；
  该档没有厂商 HID 通道，读的是 Windows 的 BLE 电池属性，
  只刷新百分比、不含充放电状态，刷新频率取决于系统上报。
· 键盘切到「蓝牙档」后：卡片自动显示「蓝牙」，0x13 帧原样可用（已实测通过）；
  蓝牙链路从省电态唤醒约需 1 秒，首次读数可能比 2.4G 慢，属正常。
· 想改刷新频率或阈值：编辑 @Resources\Variables.inc 里的
  RefreshMinutes / LowBattery / CriticalBattery / SoundOn，保存后右键刷新皮肤。
· 想听低电提示音：把 Variables.inc 里的 SoundOn 改成 1（默认 0 = 静音）。

说明
----
本皮肤不修改系统设置，也不常驻后台进程。采集在线程池里执行，界面只读缓存，
不会因为设备休眠等待超时而卡住 Rainmeter。
